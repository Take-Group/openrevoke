# open-revoke/frontend/src/hooks/

React Query hooks, one file per API resource; components call these and never `fetch`. Reads use `useQuery` with `apiGet` (`lib/api/client.ts`); writes use `useApiMutation`, which invalidates by the first element of the query key (`ResourceKey`), always refreshes `dashboard` and `audit`, and toasts the API `detail` on error. Add a new key to `ResourceKey` first.

- `use-api-mutation.ts`: `useApiMutation({mutationFn, invalidate, success, toastErrors})` and the `ResourceKey` union of top-level query keys.
- `use-accounts.ts`: `useAppAccounts(appId, params)` GET `/api/apps/{id}/accounts`, key `["accounts", appId, params]`, page of `AccountOut`; `useCreateAccount(appId)` POST same path; `useUpdateAccount()` PATCH `/api/accounts/{id}`.
- `use-actions.ts`: `useActions(params, enabled)` GET `/api/actions`, key `["actions", params]`, `ActionList`, polls 2 s while `isMoving`; `useCreateAction`, `useActionTransition(approve | cancel | complete | retry | by-hand)` POST `/api/actions/{id}/...`, `useApproveBatch` (warns about apps with writes off), `useRevealSecret` (one-time secret, does not refresh the list).
- `use-access-requests.ts`: `useAccessRequests(params, enabled)` GET `/api/access-requests` (filters), key `["access-requests", params]`; `useAccessRequest(id)` `["access-requests", "detail", id]`; `useDecideAccessRequest(id, approve | reject)`; `accessRequestsExportUrl(filters)` (CSV link).
- `use-access-profiles.ts`: everything under key `["access-profiles", ...]`: `useAccessProfiles`, `useAccessProfile(id)`, `useAccessProfileMembers(id)`, `useAppRoleSuggestions` (Map app id to roles), `usePersonAccessProfiles(personId)`, `usePersonAccessDrift(personId)`; `useCreateAccessProfile`, `useUpdateAccessProfile(id)`, `useDeleteAccessProfile(id)`, `useAssignPersonProfiles(personId)` and `useAssignProfileMembers(profileId)` (also `dry_run` previews, no toast), `useUnassignPersonProfile(personId)`, `useCreateRemovals` (one `delete_account` action per suggested removal).
- `use-ai-settings.ts`: `useAiSettings` GET `/api/ai-settings` key `["ai-settings"]`; `useSaveAiSettings`, `useAiModels` (Connect, no toast), `useSavedAiModels`, `useTestAi`.
- `use-api-tokens.ts`: `useApiTokens` GET `/api/api-tokens` key `["api-tokens"]`; `useCreateApiToken`, `useRevokeApiToken`.
- `use-apps.ts`: `useApps(params)` GET `/api/apps` key `["apps", params]` page of `AppListItem`; `useApp(id)` GET `/api/apps/{id}` key `["app", id]` `AppDetail`; `useCreateApp`, `useUpdateApp(id)`, `useDeleteApp(id)`.
- `use-audit.ts`: `useAudit(params)` GET `/api/audit` key `["audit", params]`, page of `AuditEventOut`, filters `q`, `entity_type`, `entity_id`, `event`, `app_id`, `person_id`.
- `use-auth.ts`: `useAuthState` GET `/api/auth/state` key `["auth"]` (who is signed in, setup needed, organization); auth steps `useSetup`, `useLogin` and `useRegister` (enter the panel on `done`), `useVerifyTotp`, `useSkipTotp`, `useEnterPanel`, Settings 2FA `useStartTwoFactor`, `useSetTwoFactor`, `useSignup`, `useResetPassword`, `useChangePassword`, `useLogout` under `/api/auth/...` with `meta.authFlow` so a 401 does not reset the state; `useInviteInfo(token)` key `["auth", "invite", token]`; `useSetupTokenCheck(token)`; `useRestartAtLogin()`. Sign-in and logout clear every cache except `auth`.
- `use-browser.ts`: `useBrowserState` GET `/api/browser` key `["browser"]` (polls 15 s, not after a 4xx); `useOpenInBrowser` POST `/api/browser/open`.
- `use-catalog.ts`: `useAppCatalog()` GET `/api/catalog/apps` key `["catalog"]` (public, never stale), returns a lookup by catalog slug or app name (`keys`).
- `use-connection.ts`: `useSaveConnection(appId)` PUT `/api/apps/{id}/connection`, `useCheckConnection`, `useSyncConnection`; `useSyncRuns(appId)` GET `/api/apps/{id}/sync-runs` key `["sync-runs", appId]` (polls 3 s while a run is `running`); `useSyncInProgress(appId)` returns a boolean and refetches apps, accounts and people when the sync ends.
- `use-connectors.ts`: `useConnectors` GET `/api/connectors` key `["connectors"]`, page of `ConnectorOut` (config schema for the connection form).
- `use-currencies.ts`: `useCurrencies` GET `/api/currencies` key `["currencies"]` (stale 10 min, public); `useRefreshRates` POST `/api/exchange-rates/refresh`, refetches every list with costs.
- `use-dashboard.ts`: `useDashboard` GET `/api/dashboard` key `["dashboard"]`, `Dashboard`.
- `use-debounced-value.ts`: `useDebouncedValue(value, delay = 300)` for search inputs.
- `use-discovery.ts`: `useDiscovery` GET `/api/discovery` key `["discovery", "overview"]` (polls 3 s while `scan_running`, refetches people and apps when it ends); `useDiscoveredApps(params)` `["discovery", "apps", params]`; `useDiscoveredApp(id)`; `usePersonDiscoveredApps(personId)`; `useScanNow`, `useConnectDiscoverySource`, `useStartGoogleOAuth`, `useGoogleCloudSetup` (polls), `useStartGoogleCloudSetup`, `useUpdateDiscoveredApp(id)`, `useTrackDiscoveredApp(id)`; `useGoogleOAuthResult()` reads `?google=`/`?google_error=` once after the redirect.
- `use-me.ts`: `useMyAccess` GET `/api/me/access` key `["me", "access"]`; `useRequestAccess` POST `/api/me/access-requests`; `useMyTeam` `["me", "team"]`; `useMyApprovals(params)` `["me", "approvals", params]` (`pending`, `has_reports` for the sidebar); `useMyApproval(id)`; `useDecideMyApproval(id, approve | reject)`.
- `use-mobile.ts`: `useIsMobile()` true below 768 px (`useSyncExternalStore`).
- `use-onboarding.ts`: `useOnboarding` GET `/api/onboarding` key `["onboarding"]` (first-run answers and checklist); `useSaveOnboardingChoices` POST `/api/onboarding/choices`; `useDismissOnboarding` POST `/api/onboarding/dismiss`.
- `use-people.ts`: `usePeople(params, enabled)` GET `/api/people` key `["people", params]` `PersonPage`; `usePerson(id)` key `["person", id]` `PersonDetail`; `useCreatePerson`, `useUpdatePerson(id)`, `useSetPersonKind(id)` (PATCH), `useImportPeople` POST `/api/people/import` (`dry_run` query), `useOffboardPerson(id)` and `useOnboardPerson(id)` (create actions), `useDeletePerson(id)`.
- `use-recipe-fixes.ts`: `useRecipeFixDecision("approve" | "reject")` POST `/api/recipe-fixes/{id}/...`.
- `use-slack-agent.ts`: `useSlackAgent` GET `/api/slack-agent` key `["slack-agent"]` (polls 3 s while `connecting`), plus setup mutations.
- `use-system.ts`: `useSystemVersion` GET `/api/system/version` (admins).
- `use-url-tab.ts`: `useUrlTab(initial, fallback, param = "tab")`: state mirrored in a URL query param (`?tab=`, or e.g. `?step=` for the /welcome wizard) with `history.replaceState` (no navigation, fallback drops the param); the page reads the param on the server and passes `initial`.
- `use-users.ts`: `useUsers` GET `/api/users` key `["users"]`; `useInvites(enabled)` GET `/api/invites` key `["invites"]`; `useCreateInvite`, `useRevokeInvite`, `useApproveUser`, `useCreateResetLink`, `useUpdateUserRole`, `useResetUserTotp`, `useRemoveUser`; `useOrganizationSettings` GET `/api/organization` key `["organization"]`; `useUpdateOrganization(success)` PATCH `/api/organization` (refreshes cost views).
